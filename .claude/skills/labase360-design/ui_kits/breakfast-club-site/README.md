# UI Kit — Breakfast Club (public site)

The light, warm marketing site a prospect sees. Cream ground, orange→red CTA gradient, alternating bands, eyebrow pills, ghost numeral, framed image with offset tinted panel. Poppins body, Anton titles.

**Interactive:** any "Réserver" opens a reservation modal → confirm → success state.

## Sections
- `SiteHeader.jsx` — sticky blurred nav with wordmark + CTA.
- `Hero.jsx` — headline, ghost "360" numeral, framed medallion, CTA.
- `Sections.jsx` — `FeatureCards` (3 pillars), `DarkBand` (stats on green), `Pricing` (3 plans), `SiteFooter`.
- `SiteApp.jsx` — page + reservation modal.

Uses the real Breakfast Club logo PNGs from `assets/breakfast-club/`. Icons are Lucide (CDN).
