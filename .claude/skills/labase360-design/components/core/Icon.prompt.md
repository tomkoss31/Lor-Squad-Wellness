Icon wrapper over **Lucide** (CDN — add `<script src="https://unpkg.com/lucide@latest"></script>`). This is a flagged substitution for an unprovided brand icon set; swap for official glyphs when available.

```jsx
<Icon name="flame" size={20} color="var(--ls-coral)" />
<Icon name="check" size={16} strokeWidth={2.5} />
```

Use Lucide names. Keep stroke ~2px to match the mark's rounded terminals.
