The La Base 360 lockup. Flat SVG mark (open teal ring, lime 45° bar, white B) + HTML wordmark. Never close the ring, add shadow, or gradient-fill the B.

```jsx
<Logo tone="dark" size={44} />
<Logo tone="light" layout="stacked" />
<Logo tone="mono" showText={false} size={32} style={{ color: 'var(--ls-teal)' }} />
```

`tone`: dark (default) · light (cream grounds) · mono (currentColor). `layout`: horizontal · stacked.
