A labelled metric. Value set in JetBrains Mono (aligned numerals), mono-caps eyebrow above, optional delta. Use lime accent only for a genuine win.

```jsx
<StatBlock label="Calories" value="1 248" unit="kcal" delta="+12%" deltaTone="up" />
<StatBlock label="Objectif" value="92" unit="%" accent="var(--ls-lime)" />
```

`deltaTone`: up (lime) · down (coral) · flat.
